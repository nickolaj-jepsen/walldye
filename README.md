# walldye

Procedural SVG wallpapers, each a small seeded Python script, recoloured from three seed colours (bg, fg, accent). The site at walldye.com shows the catalogue and exports each piece as SVG, PNG, WebP or JPEG.

## Python tooling

The library (`walldye/`) and the `walldye` CLI are a [uv](https://docs.astral.sh/uv/) project pinned to Python 3.13.

```sh
uv run walldye --help
uv run walldye list
uv run walldye preview <slug> --theme nord
uv run walldye check <slug>
uv run walldye build <slug>
uv run walldye build --verify   # re-render every committed template and diff, before committing
uv run pytest
```

On NixOS the prebuilt wheels (numpy, scipy, shapely, scikit-image, resvg-py) need `programs.nix-ld.enable = true;`. There is no Nix devShell.

Each piece lives in `wallpapers/<slug>/`: `design.py` and `meta.yaml` are written by hand, and `build/` is generated by `walldye build` and committed.

## Site

```sh
pnpm install
pnpm dev
pnpm build
pnpm test              # vitest
pnpm check-artifacts   # committed builds against their inputs, as CI runs it
pnpm e2e:nix           # Playwright on NixOS; `pnpm e2e` elsewhere
```

Design decisions are in [docs/design.md](docs/design.md) and the deploy setup in [docs/deploy.md](docs/deploy.md).
